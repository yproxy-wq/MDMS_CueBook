# CueBook Portal

既存のCueBookアプリとは独立した、ポータルサイトの初期プロジェクトです。

## 起動

ビルドツールなしで `index.html` をブラウザで開けます。ローカルサーバーを使う場合は、プロジェクト直下で任意の静的サーバーを起動してください。

## 差し替え箇所

- Stable版リンク: `index.html` 内の `https://cuebook-stable.web.app/`
- 実画面素材: `assets/`
- デザインとレスポンシブ: `styles.css`

## 方針

- 既存アプリのコード・依存関係・Firebase設定は参照するだけで変更しない。
- Hallmarkの編集的な余白・罫線・構造の変化と、CueBookの暗い技術的UIを組み合わせる。
- デスクトップではヒーロー＋システム＋出力の短い構成、モバイルでは縦積みへ落とす。
